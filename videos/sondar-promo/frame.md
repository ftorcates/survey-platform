# Frame Direction

Sondar debe sentirse como una herramienta que escucha senales y las convierte en mapas operativos. El video usa un sistema de radar: ondas concentricas, nodos conectados, barras de audiencia y capturas reales de producto. La composicion evita verse como dashboard generico: los datos flotan como senales, la UI aparece como evidencia y el cierre aterriza en marca.

# Motion

Entradas por barrido, orbitas lentas, ondas que se expanden, lineas que se dibujan y paneles que se desplazan en profundidad. La UI capturada debe sentirse escaneada, no simplemente pegada.
